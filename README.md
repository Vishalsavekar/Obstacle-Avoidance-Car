# 🚗 Obstacle Avoidance Robot Car

## Overview

An autonomous robot car that detects obstacles using an ultrasonic sensor and automatically changes direction.

## Features

- Obstacle Detection
- Autonomous Navigation
- Servo Based Scanning
- Real-Time Distance Measurement

## Components

- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- SG90 Servo Motor
- L298N Motor Driver
- DC Motors
- Battery Pack

## Working Principle

1. Detect obstacle.
2. Stop vehicle.
3. Scan left and right.
4. Choose safest direction.
5. Continue movement.
